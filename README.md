# AI Study Planner

A study-planning app built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Deploy to GitHub Pages

1. Push this project to a GitHub repository.
2. In the GitHub repository, go to Settings > Pages.
3. Set Source to GitHub Actions.
4. Commit and push to the `main` branch.
5. The workflow in `.github/workflows/deploy.yml` will automatically build and deploy the app.

This project is configured with Vite's `base: './'` setting so the build works correctly when published to GitHub Pages.
